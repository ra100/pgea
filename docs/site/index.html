Talk to private-VPC Aurora
with your favorite Postgres GUI.

pgea is a local TCP proxy that speaks the PostgreSQL wire protocol on the client side and translates queries into AWS RDS Data API calls on the backend. No bastion. No VPN. No port-forwarding.

What it does

Wire-level Postgres

Simple + Extended query, transaction verbs, $N parameter rewriting, prepared statements, portals.

RDS Data API backend

Each query becomes ExecuteStatement / BeginTransaction / CommitTransaction against your Aurora cluster.

GUI-friendly

Targeted catalog rewrites keep DBeaver, DataGrip, TablePlus, and psql \d introspection working.

Standard AWS auth

Credentials come from AWS_PROFILE, env, SSO, or IMDS. Per-target overrides via the pg password field.

Many targets, one proxy

Named targets in ~/.config/pgea/config.toml. The pg dbname picks the cluster.

Lazy credential resolve

Stale SSO on nine of ten targets won't break the fresh one — creds resolve on first connection.

Install

One-liner (macOS arm64, Linux x86_64):

curl -fsSL https://raw.githubusercontent.com/svarba/pg-rds-connector/main/install.sh | bash

Pin a version:

PGEA_VERSION=v0.1.1 curl -fsSL https://raw.githubusercontent.com/svarba/pg-rds-connector/main/install.sh | bash

From source:

cargo install --git https://github.com/svarba/pg-rds-connector

Update later:

pgea self-update

Configure

Drop a TOML file at ~/.config/pgea/config.toml:

listen          = "127.0.0.1:15000"
default_profile = "default"

[targets.playground_uat]
profile     = "uat"
region      = "us-east-1"
cluster_arn = "arn:aws:rds:us-east-1:123456789012:cluster:my-cluster"
secret_arn  = "arn:aws:secretsmanager:us-east-1:123456789012:secret:my-cluster-credentials-XXXXXX"
database    = "appdb"

Then run:

pgea --config ~/.config/pgea/config.toml

Connect with any pg client. The dbname selects the target; the password field is repurposed as an optional AWS profile override.

Status

Early — v1 covers connection routing, Simple + Extended Query, transaction verbs, and a focused set of catalog rewrites for GUI introspection.

Not yet supported

  • COPY, server-side cursors, LISTEN / NOTIFY, SAVEPOINT
  • Multi-statement Simple Query
  • Auto-pagination around the Data API 1 MB result cap
  • TLS to client (loopback only)
  • Prepared-statement caching across sessions

See the design spec for full scope and rationale.
